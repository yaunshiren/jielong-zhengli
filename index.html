使用前了解一下
所有数据在哪里处理？
打开网页后，解析、修改、打印和下载都在你的浏览器进行。我们没有账号或服务器接收报名名单。关闭页面后未下载的数据不会被本工具保留。
能自动识别所有接龙吗？
不能。支持常见编号行（如「1.张三」「2、李四」「3 王五」「4：小陈」），但同名、备注、随行人数、付款状态仍有歧义。工具会尽量提示异常，不会自作主张删除重复姓名。
CSV 怎么在 Excel 或 WPS 打开？
点击导出后得到 UTF-8 编码的 CSV 文件。大多数新版表格软件可直接打开；遇到乱码时，使用「数据 → 从文本/CSV」并选择 UTF-8。
是否能代表实际支付记录？
不能。已付款等状态只是从群文本里提取的文字标注，不代表任何实际到账记录。正式收款对账请使用真实交易记录。

  
遇到不能识别的接龙格式？
可提交完全匿名化的格式样例帮助改进。反馈需要 GitHub 账号；请勿上传真实姓名、电话、微信号或群聊截图。工具不会自动发送你的报名数据。
