微信群接龙如何整理成 Excel 名单？

已经在微信里接龙结束，不想要求成员重新报名？你可以直接复制现有的编号文字接龙，将它整理成可人工核对的名单，并导出 Excel/WPS 能打开的 CSV。

本工具只处理你主动粘贴的文字，无法自动读取群聊天记录。名单在浏览器本地处理，不需要上传；付款文字不能代表实际到账。

四步使用方法

第 1 步：复制接龙正文

从有权处理的群聊中复制已有的文字接龙，而不是截图。若包含手机号、身份证号等敏感内容，请先在本地删除或脱敏。

第 2 步：粘贴并开始整理

打开接龙整理台，填写活动名称，粘贴接龙文字，点击「开始整理」。初次使用可先点「载入样例」，不用提供真实报名资料。

第 3 步：人工核对名单

重点检查重名、人数、取消记录及跳过的行；工具不会自动把同名当成同一人，也不会核验实际付款。

第 4 步：导出或打印

点击「下载有效名单 CSV」，用 Excel/WPS 打开。若出现乱码，尝试「数据 → 从文本/CSV」，选择 UTF-8。需要签到时直接点击「打印 A4 签到表」。

示例中的两个“阿文”不能自动合并。同名可能是重复报名，也可能是两个人。最终名单必须人工确认。

常见问题

下载的是原生 .xlsx 吗？

不是。下载的是 UTF-8 CSV 文件，Excel/WPS 可打开，但不包含复杂格式、公式或多工作表。

能识别全部微信接龙吗？

不能。当前支持部分常见数字编号加标点/空格写法。转发引用、图片、单行多人和复杂备注可能漏识别，请查看跳过行并认真核对。

数据会上传吗？

本工具当前没有上传名单的接口，也没有访问统计脚本。静态网站的托管平台可能依其政策记录常规网络请求信息。

关闭页面之后如何恢复？

工具不会自动保存你输入的数据。离开网页前应自行下载 CSV 或打印保存。

怎样匿名反馈格式问题？

使用 GitHub 问题反馈（需要 GitHub 账号）。只提交完全虚构或彻底匿名化的示例，绝不能提交真实群聊或个人信息。
