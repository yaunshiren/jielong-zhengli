# 接龙整理台（Beta 0.1）

将已有微信群文字接龙转换为可核对名单、CSV 与 A4 签到表。完全在浏览器本地处理，不需要登录，也不上传报名文字。

**使用方法：** 打开网站 → 粘贴接龙 → 点击「开始整理」→ 检查人数、重名、取消状态 → 下载 CSV 或打印签到表。

**功能边界：** 仅识别部分常见编号文本；同名不自动合并；“已付款”只反映输入文字，不代表到账凭证。处理他人信息请取得必要授权。本项目与微信、腾讯无关联。

**商业状态：** 免费测试版，无收款功能。尚未验证真实付费需求。

## 反馈与改进

可通过本仓库 Issues 报告问题。请勿在公开 Issue 中粘贴真实报名者姓名、电话或群聊记录，尽可能使用匿名化样例。

## 部署

仓库根目录的 `index.html` 是独立单文件网页。`.github/workflows/deploy.yml` 在 `main` 分支推送时自动部署到 GitHub Pages（需在仓库 Settings → Pages 中将 Source 设为 GitHub Actions）。
